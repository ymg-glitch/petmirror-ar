# 手机 H5

这是实际项目的手机端原型，承担宠物切换、档案、照护记录、设置及纪念档案。它不显示 AR 实时分析界面。

先启动 `../backend/server.mjs`，再在本目录运行：

```powershell
node serve.mjs
```

打开 `http://127.0.0.1:8792`。H5 默认请求本机 `http://127.0.0.1:8791`。后端不在线时，首页会显示本地演示数据，涉及保存的操作需要后端。

GitHub Pages 使用 `../docs/` 的静态样例回放；它与本目录的本地联调 H5 分开，避免访客浏览器请求其自己的 `127.0.0.1`。
